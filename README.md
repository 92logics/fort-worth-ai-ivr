# Fort Worth AI IVR (prototype)

Scripted sample by [92 Logics](https://www.92logics.com) (Islamabad; CEO Qaiser Mehmood). It is not an official City of Fort Worth system and it is not a bid.

Buyer: City of Fort Worth, Texas.

Notice: https://fortworthtexas.bonfirehub.com/portal/?tab=openOpportunities

Solicitation referenced in the 92 Logics CRM (lead id 11): Fort Worth AI IVR **26-0263**. CRM deadline field: **2026-10-22**. CRM `contact_email` for this lead is empty — no verified city procurement email was recorded there.

The Bonfire open-opportunities tab did not return readable opportunity documents without login during this build, so the official RFP PDF package was not verified from the portal itself. Public secondary listings describe an as-needed enterprise AI Interactive Voice Response platform covering resident- and staff-facing voice, chat, SMS, outbound calling, and related workflow/knowledge features, with named integrations such as Cisco IVR, Microsoft 365, Accela, and ESRI/ArcGIS. Treat those scope lines as public summaries until confirmed in the city’s attachments.

The phone-assistant UI is a labeled scripted sample grounded only in public fortworthtexas.gov pages fetched for this demo (home, Customer Care / 311, Solid Waste, Recycling, Water, Water Bill FAQ). It does not place calls, send SMS, open MyFW, or look up accounts. It refuses address-level pickup days, personal balances, live transfers, and invented call volumes or city statistics.

## Run it

Open `index.html` in a browser. No install and no build step. No network connection and no API key are required.
